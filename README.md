🇬🇧 This site provides access to **[jocly2](https://github.com/fhoudebert/jocly2/)** games and lets you download extensions so you can play them offline with **[Tabulon](https://github.com/fhoudebert/tabulon)**, without requiring a server.

## Tabulon extensions

The easiest way to install extensions is from the **Extensions** screen (Hub sidebar → **Configuration**) by importing downloaded `.tabulon-ext` files.

Browse the catalog:

- [Modules](https://fhoudebert.github.io/tabulon/ext/modules/index.html) — complete game families. A **module** contains several related games and their shared resources. It can be installed directly.
- [Games](https://fhoudebert.github.io/tabulon/ext/games/index.html) — individual games. Installing a game requires that its corresponding module is already installed.
