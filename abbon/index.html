Abbon — QCM hors ligne

Abbon est une application libre de QCM qui fonctionne sans connexion, sous Linux, Windows, macOS et Android : entraînement avec correction immédiate, examens chronométrés, boîte de révision, fiches de révision.

  • Questionnaires — fichiers .qcm à importer dans Abbon, classés par langue et par rubrique
  • Atelier de formules — écrire une formule de maths ou de chimie et la coller dans Word, LibreOffice, en LaTeX ou en image (page utilisable hors ligne)
  • Télécharger l’application — dernières versions sur GitHub
  • Code source — signaler un problème, proposer un questionnaire
